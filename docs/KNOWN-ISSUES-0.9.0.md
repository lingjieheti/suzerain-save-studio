# 0.9.0 已知问题与验证范围

## 当前发布定位

本包是 **Windows x64 公开预览版**。它包含可运行的单文件程序、源码与发布资料；**尚未完成原生 Windows 和实际游戏读档的稳定版验收**。

## GUI 兼容环境中的间歇性退出

在隔离的 Wine 9 / Xvfb 环境中，真实鼠标连续操作测试出现过窗口失效，原生层输出：

```text
free(): invalid next size (fast)
```

发生点包括从修改预览或备份页返回资源页，位置并不固定。最终候选曾在“99预设 → 撤销 → 重做 → 查看预览 → 返回资源”时遇到此问题；该次尚未保存，测试副本保持原样，没有创建备份。

**根因尚未定位，Windows 真机是否受影响尚未确认。** 延迟按钮处理、明确 image list 所有权、保持栏头列稳定等改进，没有提供充分的“问题已解决”证据。加载诊断库时出现过完整流程通过，但诊断库会改变内存与时序，不能把该结果当作稳定性证明。

目标平台是 Windows 10 / 11 x64；本版不承诺 Wine、Linux 或 macOS 的运行兼容性。即使目标平台不同，上述测试异常仍作为公开的未解决项保留。

## 已有的通过证据

- 核心解析与局部写入：249项检查，在合成样本和游戏3.1.0.1.175的真实样本上均通过。
- 编辑会话、整批撤销/重做和修改方案：134项检查，在两种样本上均通过。
- 未修改时逐字节不变；修改只替换目标值，其他未知字段与战棋数据保持。
- 多轮界面操作中已成功验证资源99/999相关操作、预算250与对应上限、精确备份、拒绝非法小数、拒绝外部修改后的覆盖、备份恢复和恢复前再备份。
- 最终候选的资源页、修改预览及1060×730紧凑布局已截图检查，中文和主要按钮可读。

这些通过项不等于最终候选已经完成一次无异常的完整 GUI 回归。

## 还没有执行的验收

- Windows 10 / 11 真机的完整连续操作与150%/200%缩放。
- 修改后的存档在实际 Suzerain 游戏中载入、推进回合及后续剧情。
- 最终候选中公共文件选择对话框的全部导入、导出和另存交互；方案解析/应用/序列化的独立测试已通过。
- 数字签名。本构建未签名。
