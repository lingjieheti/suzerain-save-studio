# 0.10.1 中文字段补全

上一版只给 114 个常用字段配置了名称翻译，高级页的其他 3,983 个字段仍显示内部英文名。本版增加中文词库和名称拆解，让已检查样本中的 4,097 个可编辑字段都有中文名称：本体 1,480 个，里奇亚 2,617 个。

- 中文名称用于高级列表、中文搜索、修改预览、选中项目详情及 CSV 的名称列。
- 原值和待保存值中的 `true / false` 显示为“是 / 否”，布尔按钮也使用“是 / 否”。其他界面语言同时采用对应的布尔显示词。
- 中文长名称在详情区完整展示；复制字段名仍复制原始内部名称。
- 存档、修改方案和 CSV 数值列仍使用游戏所需的原始数字与 `true / false`，不写入翻译文本。

高级字段按内部名称提供中文释义，不承诺推断剧情效果。InT、EnT 等场景代码和无法安全展开的缩写保留原代码。繁体中文沿用转换；其他语言的高级字段名称尚未做此轮全量翻译。未来版本新增、词库尚未覆盖的词会保留原词，避免隐藏字段身份。

源码中的两个 `advanced_zh_words_*.json` 是可维护词库；修改后运行 `python tools/generate_advanced_zh.py` 更新内嵌头文件。正常使用和编译已生成的源码都不需要 Python。
