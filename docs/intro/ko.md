# Suzerain Save Studio

🌐 [언어 선택](../../README.md#languages)

예전에는 《Suzerain》을 할 때 주로 저장 파일을 직접 고쳤어요. 그때마다 같은 파일을 두 번씩 불러오는 게 번거로워서 제가 쓰려고 이 도구를 만들었습니다. 저장 파일을 편집할 수도 있고, 게임을 하면서 바로 자원 수치를 바꿀 수도 있어요. 선택지 미리보기를 켜고 선택지에 마우스를 올린 뒤 **Ctrl** 키를 한 번 누르면 지금까지 확인된 직접 효과를 볼 수 있습니다. 쓰면서 작은 기능도 몇 가지 더했어요. [이런 기능이 있으면 좋겠다는 의견도 편하게 남겨 주세요.](https://github.com/lingjieheti/suzerain-save-studio/issues)

[Windows 10 / 11 x64 미리 보기 버전 다운로드](https://github.com/lingjieheti/suzerain-save-studio/releases/download/v0.23.5/SuzerainSaveStudio-0.23.5-Live-Preview-win-x64.zip)

저장 파일 선택 창이나 편집기의 **테마** 메뉴에서 네 가지 색상 테마에 **투명**, **반투명**, **단색** 중 하나를 조합할 수 있습니다.

도구 모음 왼쪽에서는 현재 저장 파일을 다시 불러오거나 해당 폴더를 열 수 있습니다. 다른 저장 파일로 전환하려면 오른쪽을 사용하세요. [도구 모음 전후 비교](../images/file-toolbar.png)

캠페인에서 **Ctrl+F8**을 누르면 게임에서 제공하는 여론 점수를 확인할 수 있습니다. 저장 파일 편집기에서는 `PO`로 검색하세요.

**Ctrl+F8** 패널에서 선택지 미리보기를 켠 뒤 패널을 닫으세요. 선택지에 마우스를 올리고 왼쪽이나 오른쪽 **Ctrl** 키를 한 번 눌렀다 놓으면 효과가 표시됩니다. 다시 누르거나 마우스를 옮기면 설명이 사라집니다. 다른 선택지의 효과를 보려면 그 위에서 Ctrl 키를 다시 누르세요. 기본값은 꺼짐이며, 이후 전개에 따라 달라지는 결과는 미리 알 수 없을 수 있습니다.

## 저장 파일 편집

ZIP 파일의 압축을 풀고 `SuzerainSaveStudio.exe`를 실행하세요. 처음에는 내장된 소르들란트 또는 리지아 예제로 예산을 바꿔 보세요. 실제 플레이 기록을 편집할 때는 게임에서 먼저 저장하고 게임을 종료하세요. 값을 바꾼 뒤 미리 보기에서 원래 값과 새 값을 비교하고, 사본으로 저장하거나 원본에 덮어쓸 수 있습니다. 덮어쓰기 전에는 원본을 자동으로 백업합니다. 게임을 다시 실행한 뒤 메인 메뉴에서 편집한 저장 파일을 직접 불러오세요.

## 게임 중에 수치 조정

**BepInEx 6 IL2CPP**가 이미 설치되어 있다면 편집기의 ‘실시간 모드’에서 게임 내 패널을 추가할 수 있습니다. 캠페인을 불러온 뒤 **Ctrl+F8**을 누르세요. 소르들란트에서는 정부 예산과 개인 자산을, 리지아에서는 예산과 권위, 에너지를 조정할 수 있습니다. 패널은 중국어 간체와 영어를 지원하며, 변경할 값을 미리 보고 확인하면 게임에 반영됩니다.
