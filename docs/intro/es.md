# Suzerain Save Studio

🌐 [Cambiar de idioma](../../README.md#languages)

Antes, para cambiar algo en mis partidas de *Suzerain*, casi siempre editaba el archivo de guardado. Tenía que cargar la partida dos veces con cada cambio. Me cansé de hacerlo y creé este editor. Te permite editar partidas guardadas y ajustar recursos directamente en el juego. Si activas la vista previa de las decisiones, basta con pasar el cursor sobre una opción y pulsar brevemente Ctrl para ver los efectos directos que se conocen de esa elección. También hay algunas funciones más. [Si tienes alguna sugerencia, me encantará leerla.](https://github.com/lingjieheti/suzerain-save-studio/issues)

**[Descargar la versión preliminar 0.22.1 para Windows 10/11 (x64)](https://github.com/lingjieheti/suzerain-save-studio/releases/download/v0.22.1/SuzerainSaveStudio-0.22.1-Live-Preview-win-x64.zip)**

En el selector de partidas o en el editor, abre **Apariencia**. Puedes combinar cualquiera de los cuatro temas de color con el acabado **Claro**, **Esmerilado** u **Opaco**.

Pulsa **Ctrl+F8** para consultar la puntuación interna de opinión pública de la campaña cuando esté disponible. En el editor de partidas guardadas puedes buscarla con `PO`.

Activa la vista previa de las opciones en el panel **Ctrl+F8** y cierra el panel. Coloca el cursor sobre una opción y pulsa brevemente la tecla **Ctrl** izquierda o derecha para ver sus efectos. Vuelve a pulsarla o retira el cursor para cerrar la vista previa. Para comparar otra opción, coloca el cursor sobre ella y pulsa Ctrl. La función está desactivada de forma predeterminada. Algunas consecuencias dependen de cómo avance la historia.

## Editar una partida guardada

1. Descomprime el ZIP y ejecuta `SuzerainSaveStudio.exe`. Puedes probar el editor con uno de los dos ejemplos incluidos.
2. Para editar tu propia partida, guárdala y cierra el juego. Abre el archivo en el editor, busca el campo que te interesa e introduce el nuevo valor. Si lo consultas a menudo, puedes marcarlo como favorito.
3. Compara el valor anterior con el nuevo en la vista previa. Guarda una copia o sobrescribe el archivo y carga la partida modificada desde el menú principal del juego.

El complemento opcional para la versión de Steam requiere **BepInEx 6 IL2CPP**. Una vez instalado, pulsa **Ctrl+F8** durante la partida para abrir el panel, disponible en inglés y chino. En Sordland puedes ajustar el presupuesto del Estado y el patrimonio personal. En Rizia puedes ajustar el presupuesto, la autoridad y la energía. En el editor de escritorio en español, algunos campos avanzados conservan su nombre interno.
