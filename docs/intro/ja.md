# Suzerain Save Studio

🌐 [言語を選ぶ](../../README.md#languages)

『Suzerain』を遊ぶときに使っている、自作のセーブエディターです。ソードランドでもリジアでも、予算を確認したり、資源の値を少し調整したりできます。

[Windows 10 / 11 x64 プレビュー版をダウンロード](https://github.com/lingjieheti/suzerain-save-studio/releases/download/v0.16.2/SuzerainSaveStudio-0.16.2-Live-Preview-win-x64.zip)

## セーブデータを編集する

ZIP を展開し、`SuzerainSaveStudio.exe` を起動します。まずは同梱のソードランドやリジアのサンプルで、予算を少し変えてみてください。自分のセーブデータを編集するときは、ゲーム内でセーブしてからゲームを終了します。編集後はプレビューで変更前後の値を確認し、別名で保存するか、元のファイルに上書きします。上書き前にはバックアップが自動で作成されます。ゲームのメインメニューから、編集したセーブデータを読み込んでください。

## プレイ中に数値を調整する

**BepInEx 6 IL2CPP** を導入済みなら、エディターの「リアルタイム」からゲーム内パネルを追加できます。キャンペーンを読み込んで **Ctrl+F8** を押すと、ソードランドでは政府予算と個人資産、リジアでは予算・権威・エネルギーを調整できます。パネルの表示は簡体字中国語と英語に対応しています。値はプレビューで確認してから反映します。
