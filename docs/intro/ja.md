# Suzerain Save Studio

🌐 [言語を選ぶ](../../README.md#languages)

以前は『Suzerain』のセーブデータを直接編集していました。そのたびに同じセーブを2回読み込むのが面倒で、自分用に作ったのがこのツールです。セーブデータを編集したり、プレイ中に資源の数値を変えたりできます。プレビューを有効にして選択肢にカーソルを合わせ、**Ctrl** を一度押すと、判明している直接の効果を確認できます。ほかにも小さな機能をいくつか加えました。[こんな機能がほしい、というご意見もぜひお寄せください。](https://github.com/lingjieheti/suzerain-save-studio/issues)

[Windows 10 / 11 x64 プレビュー版をダウンロード](https://github.com/lingjieheti/suzerain-save-studio/releases/download/v0.23.3/SuzerainSaveStudio-0.23.3-Live-Preview-win-x64.zip)

セーブ選択画面やエディターの「外観」で、4 種類の配色それぞれに「クリア」「すりガラス」「単色」のいずれかを組み合わせられます。

キャンペーン中に **Ctrl+F8** を押すと、ゲームから取得できる場合に世論の内部スコアが表示されます。セーブエディターでは `PO` で検索できます。

選択肢の効果を事前に見るには、**Ctrl+F8** でパネルを開き、選択肢のプレビューを有効にしてからパネルを閉じます。選択肢にカーソルを合わせ、左右どちらかの **Ctrl** キーを軽く押すと効果が表示されます。もう一度押すか、カーソルを外すと閉じます。別の選択肢を確認するときは、その上で再度 Ctrl を押してください。初期設定はオフです。その後の展開によって決まる結果は表示できない場合があります。

## セーブデータを編集する

ZIP を展開し、`SuzerainSaveStudio.exe` を起動します。まずは同梱のソードランドやリジアのサンプルで、予算を少し変えてみてください。自分のセーブデータを編集するときは、ゲーム内でセーブしてからゲームを終了します。編集後はプレビューで変更前後の値を確認し、別名で保存するか、元のファイルに上書きします。上書き前にはバックアップが自動で作成されます。ゲームのメインメニューから、編集したセーブデータを読み込んでください。

## プレイ中に数値を調整する

**BepInEx 6 IL2CPP** を導入済みなら、エディターの「リアルタイム」からゲーム内パネルを追加できます。キャンペーンを読み込んで **Ctrl+F8** を押すと、ソードランドでは政府予算と個人資産、リジアでは予算・権威・エネルギーを調整できます。パネルの表示は簡体字中国語と英語に対応しています。値はプレビューで確認してから反映します。
