# Suzerain Save Studio

🌐 [選擇語言](../../README.md#languages)

這是我玩《Suzerain》時為自己做的存檔編輯器，平常用來查預算、調整資源。在這裡分享給同樣喜歡索德蘭和里奇亞的玩家。

[下載 Windows 10 / 11 x64 預覽版](https://github.com/lingjieheti/suzerain-save-studio/releases/download/v0.15.0/SuzerainSaveStudio-0.15.0-Live-Preview-win-x64.zip)

## 編輯存檔

解壓縮後執行 `SuzerainSaveStudio.exe`。第一次使用可以先開啟內建的索德蘭或里奇亞範例，試著調整預算。要編輯自己的進度，請先在遊戲中存檔並退出。修改後先預覽新舊數值，再另存副本或寫回原檔。寫回前會自動備份。回到遊戲主選單，手動載入剛修改的存檔。

## 在遊戲中微調

如果已安裝 **BepInEx 6 IL2CPP**，可從編輯器的即時模式安裝選用的遊戲內面板。載入戰役後按 **Ctrl+F8**，即可調整索德蘭的政府預算與個人財富，或里奇亞的預算、權威與能源。面板支援簡體中文和英文，數值會在預覽並確認後寫入。
