# Suzerain Save Studio

🌐 [選擇語言](../../README.md#languages)

我以前玩《Suzerain》主要靠改存檔，每次都要讀兩次檔，覺得有點麻煩，就給自己做了這個修改器。現在既可以改存檔，也可以直接在遊戲裡調整資源。開啟選項預覽後，把滑鼠移到選項上，輕按一下 **Ctrl** 就能看到已知的直接效果。我還順手做了幾個小功能，歡迎大家[提提建議](https://github.com/lingjieheti/suzerain-save-studio/issues)～

[下載 Windows 10 / 11 x64 預覽版](https://github.com/lingjieheti/suzerain-save-studio/releases/download/v0.22.0/SuzerainSaveStudio-0.22.0-Live-Preview-win-x64.zip)

載入戰役後按 **Ctrl+F8**，即可查看遊戲提供的民意分值。在桌面編輯器搜尋「民意」或 `PO`，也能找到存檔裡的公眾支持度。

按 **Ctrl+F8** 開啟面板，啟用選項結果預覽後關閉面板。將滑鼠指向選項，輕按一下左邊或右邊的 **Ctrl** 鍵即可查看效果。再按一次或移開滑鼠即可收起提示。想查看其他選項時，將滑鼠移過去再按 Ctrl。這項功能預設關閉，部分結果要等後續劇情才能確定。

## 編輯存檔

在選檔視窗或編輯器開啟「外觀」，即可更換中文字體。自動模式優先使用電腦上的蘋方繁體，其次為 Microsoft JhengHei UI。你也可以選擇已安裝的 Noto Sans TC。

解壓縮後執行 `SuzerainSaveStudio.exe`。第一次使用可以先開啟內建的索德蘭或里奇亞範例，試著調整預算。要編輯自己的進度，請先在遊戲中存檔並退出。修改後先預覽新舊數值，再另存副本或寫回原檔。寫回前會自動備份。回到遊戲主選單，手動載入剛修改的存檔。

## 在遊戲中微調

如果已安裝 **BepInEx 6 IL2CPP**，可從編輯器的即時模式安裝選用的遊戲內面板。載入戰役後按 **Ctrl+F8**，即可調整索德蘭的政府預算與個人財富，或里奇亞的預算、權威與能源。面板支援簡體中文和英文，數值會在預覽並確認後寫入。
