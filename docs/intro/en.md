# Suzerain Save Studio

🌐 [Languages](../../README.md#languages)

I used to edit my *Suzerain* saves by hand. Loading the same save twice every time got old, so I made this tool for myself. You can edit a save file or adjust resources while you play. With choice previews turned on, hover over a choice and tap **Ctrl** to see its known direct effects. I’ve added a few other little features along the way. [I’d love to hear your suggestions.](https://github.com/lingjieheti/suzerain-save-studio/issues)

**[Download the Windows 10/11 x64 preview](https://github.com/lingjieheti/suzerain-save-studio/releases/download/v0.18.1/SuzerainSaveStudio-0.18.1-Live-Preview-win-x64.zip)** · [Release notes and checksum](https://github.com/lingjieheti/suzerain-save-studio/releases/tag/v0.18.1)

To check a choice before selecting it, enable **Preview choices with Ctrl** in the **Ctrl+F8** panel, then close the panel. Point to a choice and tap either Ctrl key. Tap Ctrl again or move away to hide the tooltip. To preview another choice, point to it and tap Ctrl. The feature is off by default. Some later outcomes depend on how the story unfolds.

## Try a save

In the Simplified and Traditional Chinese interfaces, open the appearance menu to choose a local Chinese typeface. The automatic setting looks for the matching PingFang family first, followed by the Windows Chinese UI font.

1. Extract the ZIP and open `SuzerainSaveStudio.exe`. Pick a built-in sample to try the editor, or save and quit your game before opening your own file.
2. Search for a field, enter a value and choose **Apply**. Open **Review changes** to compare the old and new values. Use **Save as** to create a copy. The editor makes a backup when you overwrite a save.
3. Return to the game’s main menu and load the edited save.

## Adjust a resource while playing

The optional in-game panel requires BepInEx 6 IL2CPP. Choose **Live mode** in the editor to install the plugin, then load a campaign and press **Ctrl+F8**. In Sordland you can adjust government budget and personal wealth. In Rizia you can adjust budget, authority and energy. Preview the new value and confirm to write it to the running game.

The panel is available in English and Chinese. Sordland budget and wealth changes have been checked in a live campaign. Rizia’s live resource controls have been tested in simulation. [Verification details](../../VALIDATION.md)
