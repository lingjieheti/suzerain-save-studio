# Interface languages

[Read the project introduction in your language](../README.md#languages).

The main controls and curated field names support Simplified Chinese, Traditional Chinese, English, Japanese, Korean, German, French, Spanish, Brazilian Portuguese, Russian and Turkish. Choose a language in the editor. The setting persists between sessions.

Chinese includes descriptions and generated names for the 4,097 advanced identifiers covered by the tested saves. For other languages, advanced fields can retain their raw game names. Longer explanations and uncommon errors may use English. Translations have not been reviewed by native speakers.

Display names, translated Boolean values and search aliases are presentation only. The game file retains its identifiers and numeric or Boolean values.
