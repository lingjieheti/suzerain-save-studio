# Suzerain Save Studio 0.10.0 预览版

原“里奇亚存档工坊”双战役、多语言新版。适用于 Windows 10 / 11 x64，双击 `SuzerainSaveStudio.exe` 即可使用。

## 操作

退出游戏 → 选择存档 → 修改并应用 → 检查修改 → 保存 → 在游戏内重新读档。

启动自动查找常用存档目录，按修改时间排序；支持本体/里奇亚筛选、文件名与战役名搜索、刷新和添加文件夹。添加的目录在本次运行期间有效。右上角切换语言。

## 本次增加

- **11 种语言**：简中、繁中、英语、日语、韩语、德语、法语、西语、巴西葡语、俄语、土耳其语。主操作与常用字段名称均已翻译；中文含字段说明，其他语言的较长说明、少见报错与未知游戏字段可能显示英文。未经过母语审校。
- **本体**：51 项常用字段，涵盖经济、地区发展、民意、政治倾向、改革投票、家人关系、外交及军事；预算 +5、私人资产 +5。
- **里奇亚 DLC**：63 项常用字段，涵盖资源、收入与支出、军备、家族、人物和外交；资源 99/999 与自动同步上限。
- **通用功能**：当前战役的高级数值/布尔字段搜索、复制字段名、CSV 导出、修改方案导入导出、撤销重做、修改预览、另存、自动备份与恢复。

按存档内部战役标记识别本体与 DLC，限制各自字段与修改方案；拒绝跨战役覆盖和恢复。只修改存档中已有的字段。显示值不一定是百分比，修改数值不会自动重演剧情、通过改革或生成部队。

## 验证与限制

21 份真实存档完成只读解析及内存内改写核验；保存、备份和恢复用合成文件核验，未改动玩家原档。完整记录见 `VALIDATION.md`。

尚未完成“修改后在实际游戏中读档”验证，保留预览版标识。程序未数字签名；旧 0.9.0 在 Wine 下曾间歇退出，原因未定位，本版不承诺 Wine 支持。非 Torpor Games 官方工具。

单独 EXE 可用。完整包另外包含源码、构建与测试脚本、许可证、合成演示存档和验证记录。演示存档仅用于展示界面，不能在游戏里读取。语言偏好保存在 `%LOCALAPPDATA%\SuzerainSaveStudio\settings.ini`。
